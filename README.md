# FoodOrderingSystem
A simple console-based Online Food Ordering System developed in C. Users can select veg or non-veg items, place multiple orders, and generate the final bill. This project demonstrates the use of conditional statements, loops, switch-case, and basic programming concepts in C.


# Online Food Ordering System (C)

## Overview
This is a simple console-based Online Food Ordering System developed in C. It allows users to order vegetarian or non-vegetarian food items, add multiple items, and calculate the final bill.

## Features
- Veg and Non-Veg menu
- Multiple item selection
- Bill calculation
- User-friendly console interface
- Menu-driven program

## Technologies Used
- C Programming
- GCC Compiler / VS Code

## Concepts Used
- Variables
- if-else statements
- switch-case
- Loops
- Functions (if used)
- User input/output
